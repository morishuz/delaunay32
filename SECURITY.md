# Security policy

The latest tagged release and the current `main` branch receive security fixes.
Older release lines are not maintained separately.

Please report suspected vulnerabilities privately through GitHub's
**Report a vulnerability** feature for this repository. Include reproduction
steps, affected versions, impact, and any suggested mitigation. If private
reporting is unavailable, open a public issue requesting a private maintainer
contact without including vulnerability details.

Ordinary correctness bugs and malformed-input behavior that do not have a
security impact should use the public issue tracker.
